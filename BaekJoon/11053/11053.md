# 코드
```
#include <iostream>
#include <vector>

int DP_LIS(std::vector<int> nums, int lim, int idx, std::vector<int> &length)
{
  if (length[idx] != 0)
  {
    return length[idx];
  }
  length[idx] = 1;
  for (int i = idx + 1; i < lim; i++)
  {
    int tmp = DP_LIS(nums, lim, i, length);
    if (nums[i] > nums[idx])
    {
      length[idx] = std::max(length[idx], tmp + 1);
    }
  }
  return length[idx];
}

int main() 
{
  int A;
  std::cin >> A;
  std::vector<int> Aj(A);
  for (int i = 0; i < A; i++)
  {
    std::cin >> Aj[i];
  }
  std::vector<int> length(A, 0);
  DP_LIS(Aj, A, 0, length);
  int max = -1;
  for (int i = 0; i < A; i++)
  {
    if (max < length[i])
    {
      max = length[i];
    }
  }
  std::cout << max << std::endl;
  return 0;
}
```

# 풀이 과정
각 위치에서의 만들 수 있는 최대 길이 증가 수열을 구한 뒤  
그 중 최장 길이를 선택하였다.  
  
그리고 코드를 DP라고 지었는데 이것은 DP와 Memoization의 차이점을 몰랐기 때문이다.  
내가 풀어낸 방식의 정확한 명칭은 Memoization이 맞다.  
Memoization과 DP 모두 계산의 중복을 막기 위해 한 번 계산된 결과를 저장해두고 다시 사용한다는 개념은 비슷하지만  
Top down방식이냐 Bottom up방식이냐에 차이가 있다.  
Top down이면 Memoization, Bottom up이면 Dynamic Programming이다.  
이 문제는 DP를 이용하면 O(NlogN)까지 시간 복잡도를 줄일 수 있다고 한다.  

# 더 좋은 코드
```
#include <iostream>
#include <vector>
#include <algorithm> // For std::lower_bound

int LIS_BinarySearch(const std::vector<int>& nums) {
    std::vector<int> dp; // This will store the smallest end values
    for (int num : nums) {
        // Perform binary search to find the correct position of num in dp
        auto it = std::lower_bound(dp.begin(), dp.end(), num);
        if (it == dp.end()) {
            // If num is larger than all elements in dp, append it
            dp.push_back(num);
        } else {
            // Otherwise, replace the element at the found position
            *it = num;
        }
    }
    // The size of dp is the length of the LIS
    return dp.size();
}

int main() {
    int A;
    std::cin >> A;
    std::vector<int> Aj(A);
    for (int i = 0; i < A; i++) {
        std::cin >> Aj[i];
    }
    std::cout << LIS_BinarySearch(Aj) << std::endl;
    return 0;
}
```
bottom up 방식을 사용하였다.  
저장한 수보다 큰 수 중 가장 작은 수들을 차례대로 저장하며 진행한다.
