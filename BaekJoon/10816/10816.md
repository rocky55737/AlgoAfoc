# 코드
```
#include <iostream>
#include <vector>
#include <algorithm>

int main() 
{
  int n;
  std::cin >> n;
  std::vector<int> cards(n);
  for (int i = 0; i < n; i++) {
    std::cin >> cards[i];
  }
  std::sort(cards.begin(), cards.end());
  int m;
  std::cin >> m;
  std::vector<int> targets(m);
  for (int i = 0; i < m; i++) {
    std::cin >> targets[i];
  }
  for (int i = 0; i < m; i++){
    int target = targets[i];
    auto lower = std::lower_bound(cards.begin(), cards.end(), target);
    auto upper = std::upper_bound(cards.begin(), cards.end(), target);
    std::cout << upper - lower << " ";
  }
  return 0;
}

```

# 풀이 과정
처음에는 이분탐색으로 n개의 카드 중 맞는 값을 찾은 뒤  
한 칸씩 앞뒤로 같은 값의 카드들을 찾으며 cnt를 늘려주었다.  
그러자 하나의 카드를 찾는데는 logn이 걸렸으나 전체 n이 같은 값일 땐  
한칸씩 세어주며 선형탐색만큼의 시간이 걸렸다. -> O(m * n)  
  
찾아보니 lower_bound, upper_bound는 이분탐색으로 target보다 크지 않은, 작지 않은 iterator을 반환한다.  
따라서 n개의 배열을 sorting하는데 걸리는 시간 O(nlogn),  
lower bound와 upper bound를 찾는데 걸리는 시간 O(logn),  
m개의 target에서 lower, upper을 찾으므로 O(mlogn),  
O(nlogn) + O(mlogn) = O((m + n)logn) 이 걸리게 된다.
